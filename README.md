# Это-Тек - Website Oficial

## 🚀 Sobre o Projeto

Este repositório contém a base de código do site oficial da Это-Тек, desenvolvido como uma aplicação multi-página (MPA) estática e leve para garantir máxima performance de carregamento e baixo consumo de recursos no servidor.

Para mais informações sobre a empresa, visite o perfil oficial no Instagram:
👉 [@eto_tek](https://www.instagram.com/eto_tek/)
